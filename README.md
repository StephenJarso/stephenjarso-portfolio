# Jarso Systems

Build a modern, professional personal portfolio website for **Stephen Jarso**, a backend-focused software developer specializing in **Go, backend engineering, DevOps, and security**.

The website should feel like the portfolio of a real software engineer, not a generic AI-generated developer template.

## Core positioning

The main professional identity should be:

**Backend Developer • Go • DevOps • Security**

The website should communicate that Stephen builds practical software systems and is interested in what happens beyond the UI: APIs, databases, networking, infrastructure, deployment, reliability, and security.

Do NOT position him primarily as a frontend developer or designer.

---

# DESIGN DIRECTION

Create a clean, sophisticated engineering-focused visual identity.

Avoid:

* Generic SaaS landing-page design
* Excessive gradients
* Neon colors
* "Hacker" clichés
* Huge glowing text
* Floating blobs
* Excessive glassmorphism
* Stock photography
* Cartoon illustrations
* Generic developer illustrations
* Overuse of emojis

The design should feel:

* Technical
* Minimal
* Professional
* Calm
* Modern
* Slightly editorial
* Engineering-focused
* Credible to technical recruiters and engineers

Use generous whitespace and strong typography.

The website should look excellent on both desktop and mobile.

---

# COLOR SYSTEM

Use a restrained, warm technical palette.

Primary background:

* Off-white / very light warm gray

Primary text:

* Near-black / charcoal

Secondary text:

* Muted gray

Accent:

* Deep olive / muted green

Secondary accent:

* Warm sepia / beige

Use accent colors sparingly.

Do not make the entire site green.

# INTERACTION & ANIMATION

Use subtle animations throughout.

Examples:

* Fade/slide sections into view
* Gentle hover states
* Project cards slightly lift on hover
* Buttons have subtle transitions
* Architecture diagrams animate very slowly
* Navigation transitions smoothly

Do NOT use:

* excessive parallax
* spinning objects
* constant movement
* flashy particle backgrounds
* distracting animations

The website should feel fast and professional.

Respect `prefers-reduced-motion`.

# FINAL DESIGN GOAL

The final website should make a technical recruiter understand within approximately 30–60 seconds:

1. Who Stephen is
2. What kind of developer he is
3. What technologies he works with
4. What he has built
5. How he thinks about engineering
6. Where they can see his code
7. How they can contact him

The final impression should be:

**"This is an engineer who builds and understands systems."**

Not:

**"This is someone who made a pretty developer portfolio."**

Prioritize clarity, credibility, technical depth, typography, whitespace, and excellent project presentation over decorative effects.
